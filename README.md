# UCLA Mobile Order Prototype

A front-end prototype for a UCLA mobile ordering experience.

## Project structure

```text
ucla-mobile-order/
├── index.html
├── styles.css
├── script.js
└── assets/
    └── turkey-caprese.jpg
```

## Run locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

No build step or framework is required.

## Notes

- The prototype is intentionally front-end only.
- Mock locations, meals, order details, and interactions are stored in `script.js`.
- Styling is separated into `styles.css`.
- The food image is stored as a regular asset instead of a large base64 data URI.
